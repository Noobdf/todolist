# Lista de tarefas

Aplicação de estudo construída com HTML, CSS e JavaScript para praticar manipulação do DOM e eventos do navegador.

## Funcionalidades

Adicionar e editar tarefas.

Marcar tarefas como concluídas.

Excluir tarefas.

Pesquisar pelo texto das tarefas.

Filtrar entre todas, concluídas e pendentes.


## Como executar

1. Clone o repositório:

   ```sh
   git clone https://github.com/Noobdf/todolist.git
   ```

2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou executar um processo de build. Os ícones do Font Awesome são carregados por CDN e precisam de conexão com a internet.

## Estrutura

`index.html`: estrutura da página.

`css/stales.css`: estilos utilizados pela aplicação.

`js/scripts.js`: criação, edição, busca e filtros das tarefas.

`img/`: imagens do projeto.
